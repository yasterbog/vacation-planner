# Планировщик отпускных

Калькулятор отпускных по правилам РФ: средний заработок (Положение № 922), НДФЛ по прогрессивной шкале, производственный календарь, график выплат до и после отпуска, сравнение дат.

Страница статическая, считает всё в браузере. Личные данные (оклады, отпуска, выписки) в этом репозитории не хранятся: страница загружает их из отдельного закрытого репозитория через токен доступа, который вводится один раз на каждом устройстве.

## Сборка

```
node build.js
```

- `src/engine.js` — расчёт: календарь, НДФЛ, зарплата, премии, отпускные, сверка с выпиской.
- `src/app.html`, `src/app.js` — интерфейс.
- `index.html` — собранный сайт для GitHub Pages.
- `dist/artifact.html` — версия для артефакта Claude (не коммитится).
